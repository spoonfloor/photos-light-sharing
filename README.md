# Photos Light Share Viewer

Static viewer for shared photo albums. **UI is generated from the main app**
(`static/css/styles.css` + fragments) — do not maintain a parallel stylesheet here.

Deploy the contents of this folder to
[photos-light-sharing](https://github.com/spoonfloor/photos-light-sharing) for
GitHub Pages.

## URL format

`https://spoonfloor.github.io/photos-light-sharing/?s={slug}`

## Build (required before deploy)

From repo root:

```bash
./scripts/build-share-viewer.sh
```

This copies `static/css/styles.css`, self-hosted Material Symbols, and HTML
fragments from `static/fragments/share*.html` into `share-viewer/`.

Intentional share-only UI differences are documented in
[`docs/share-ui-deltas.md`](../docs/share-ui-deltas.md) and
`static/css/share-overrides.css`.

## Setup

1. Apply `../supabase/migrations/20260812140000_share_albums.sql` in Supabase.
2. Copy `js/config.js` values if your Supabase project differs.
3. Run the build script, then push this folder to the GitHub Pages repo.

## Local preview

```bash
./scripts/build-share-viewer.sh
cd share-viewer
python3 -m http.server 8080
```

Open `http://localhost:8080/?s=your-slug`.
