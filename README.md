# Photos Light Share Viewer

Static viewer for shared photo albums. **UI is inherited from the main app**
(shared CSS, `photoSurface/*` modules, `viewCapabilities.js`) — do not fork UI
logic here.

Deploy the contents of this folder to
[photos-light-sharing](https://github.com/spoonfloor/photos-light-sharing) for
GitHub Pages.

## URL format

`https://spoonfloor.github.io/photos-light-sharing/?s={slug}`

## Build (required before deploy)

From repo root:

```bash
./scripts/build-share-viewer.sh
```

## Source vs generated

| Edit here | Generated by build — do not edit |
|---|---|
| `js/config.js` | `index.html` |
| `static/js/shareBoot.js` | `js/shareBoot.js`, `js/viewCapabilities.js`, `js/photoSurface/*` |
| `static/fragments/share*.html` | (assembled into `index.html`) |
| | `css/styles.css`, fonts, `css/share-overrides.css` |

Intentional share-only differences: [`docs/share-ui-deltas.md`](../docs/share-ui-deltas.md)

## Local preview

```bash
./scripts/build-share-viewer.sh
cd share-viewer
python3 -m http.server 8080
```

Open `http://localhost:8080/?s=your-slug`.
