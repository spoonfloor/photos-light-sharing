# Photos Light Share Viewer

Static viewer for shared photo albums. **UI is inherited from the main app**
(shared CSS, `photoSurface/*` modules, `viewCapabilities.js`) — do not fork UI
logic here.

Deploy the contents of this folder to
[photos-light-sharing](https://github.com/spoonfloor/photos-light-sharing) for
GitHub Pages.

## URL format

`https://spoonfloor.github.io/photos-light-sharing/?t={access_token}`

Legacy `?s=` links still resolve during the transition window (token backfilled from slug).

Data loads via Supabase Edge Function `share-resolve` (signed storage URLs). The viewer does not call PostgREST or public storage paths.

## Build (required before deploy)

From repo root:

```bash
./scripts/build-share-viewer.sh
```

## Deploy (GitHub Pages)

After building, push to the live viewer repo:

```bash
./scripts/deploy-share-viewer.sh
```

This syncs `share-viewer/` to [photos-light-sharing](https://github.com/spoonfloor/photos-light-sharing) (`main` → Pages). Run after every share UI change.

Intentional share-only differences: [`docs/share-ui-deltas.md`](../docs/share-ui-deltas.md)

## Local preview

```bash
./scripts/build-share-viewer.sh
cd share-viewer
python3 -m http.server 8080
```

Open `http://localhost:8080/?t=your-token` (or `?s=` for legacy shares).
